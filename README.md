
# NewsStream — TDD

Aplicação desenvolvida com Node.js, Express e EJS, com testes automatizados utilizando Vitest.

## Tecnologias

- Node.js
- Express
- EJS
- MySQL
- Sequelize
- Vitest
- Supertest
- Axios

## Pré-requisitos

- Node.js e npm instalados.
- Banco de dados MySQL disponível e configurado, caso exigido pela aplicação.

## Instalação

Clone o repositório e acesse a pasta do projeto:

```bash
git clone https://github.com/vTurmina/NewsStream---TDD.git
cd NewsStream---TDD
```

Instale as dependências:

```bash
npm install
```

## Execução

Para iniciar a aplicação:

```bash
npm start
```

Para iniciar em modo de desenvolvimento:

```bash
npm run dev
```

## Testes

Executar os testes em modo interativo:

```bash
npm test
```

Executar os testes uma vez:

```bash
npm run test:run
```

Abrir a interface de testes:

```bash
npm run test:ui
```

Executar os testes com cobertura:

```bash
npm run test:coverage
```

## Configuração

Configure as variáveis de ambiente necessárias antes de executar a aplicação. Não envie senhas, tokens ou outras credenciais ao repositório.

## Estrutura do projeto

- `src/`: código-fonte da aplicação.
- `test/`: testes automatizados.
- `package.json`: dependências e scripts.
- `package-lock.json`: versões resolvidas das dependências.
- `vitest.config.js`: configuração do Vitest.
